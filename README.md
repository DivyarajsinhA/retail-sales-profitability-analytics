# Retail Sales & Profitability Analytics | Portfolio Website

Live Portfolio: **https://retail-sales-analytics-portfolio.vercel.app/**  
GitHub Project Repository: **https://github.com/DivyarajsinhA/retail-sales-profitability-analytics**

A clean, light-theme, corporate Data Analyst portfolio website built with semantic **HTML5, CSS3, and plain JavaScript**, designed for recruiters and hiring managers evaluating entry-level Data Analyst and Business Intelligence candidates.

## Included Files

- `index.html` — Complete 14-section recruiter-ready BI portfolio with verified KPIs, Star Schema diagram, Power BI report-page specifications, verified business insights, DAX measure library, and developer profile
- `styles.css` — Modern light SaaS / corporate BI stylesheet (white & light grey surfaces, dark navy headings, blue & teal accents, responsive layout)
- `script.js` — Interactive DAX category tabs, copy-to-clipboard, Chart.js visualizations using verified dataset metrics, mobile menu, and scroll spy
- `vercel.json` — Clean static hosting configuration for Vercel

## Adding Exported Power BI Screenshots Later

Each report page card in `#dashboard` includes a `data-screenshot-slot` attribute (`page1`, `page2`, `page3`). Once you export real screenshots from Power BI Desktop, save them under `assets/screenshots/` and insert an `<img>` element inside the corresponding card without redesigning the section.

## Deploy to Vercel

Replace your repository files with this folder and push to GitHub—Vercel will automatically build and deploy to `https://retail-sales-analytics-portfolio.vercel.app/`.
